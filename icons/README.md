# Archive icon set

Six original, application-neutral SVG icons informed by common conventions in
Material Symbols, Lucide, Tabler Icons, and Bootstrap Icons. The drawings are
not copied from a proprietary application or file-format logo.

## File categories

- `3d-project-file.svg`: a folded file containing a primary object plus related
  scene objects, distinguishing a multi-object project from a single model.
- `image-file.svg`: the established landscape-and-sun image metaphor.
- `3d-model-file.svg`: a single isometric solid representing model geometry.
- `document-text-file.svg`: horizontal text lines inside a folded file.
- `creative-project-file.svg`: geometric composition and a Bezier path for
  layered creative-source files such as PSD, AI, INDD, and IDML projects.

These file icons use the same 64×64 viewBox, 2.6px outline, round caps, round
joins, and neutral `#666862` stroke. They can be recolored by replacing the
stroke or changing it to `currentColor` when inlining the SVG.

## Interface symbols

- `pointer-head.svg`: a stemless, northwest-facing mouse-pointer head with a
  balanced traditional arrow silhouette, rendered as one minimalist light-grey
  `#B8B9B5` filled shape with no outline.
